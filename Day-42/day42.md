# Day 42 – Personal Financial Command Center 💰

## #60 Days of the Claude Challenge

## Project Overview

Today I built a **Personal Financial Command Center**, an AI-inspired financial dashboard that helps students and individuals manage their monthly allowance, track expenses, monitor budgets, plan savings goals, and visualize their financial health through an interactive interface.

The dashboard combines budgeting, expense tracking, financial analytics, goal planning, and educational content into one modern application.

# Key Learnings

### Financial Dashboard Design

Learned how multiple financial metrics can be presented clearly without overwhelming the user.

### Data Visualization

Discovered how charts, progress indicators, and summary cards make financial information easier to understand.

### Interactive Simulations

The What-If Planner demonstrated how small changes in daily spending can significantly impact monthly and yearly savings.

### User Experience

Designed an intuitive workflow where budgeting, spending, and savings can all be managed from one interface.

### Frontend Development

Improved skills in:
- HTML5
- CSS3
- JavaScript
- Component-based UI Design
- Responsive Layouts
- Local Storage Management


# Biggest Insight

The **What-If Planner** was the most impactful feature. Seeing projected monthly and yearly savings update instantly with simple slider adjustments highlighted how even small daily spending changes can lead to substantial long-term savings.
