# Day 45 – AI Decision Strategist

### 60 Days of Claude AI Challenge

## 📌 Project Overview

**AI Decision Strategist** is an AI-powered web application that helps users make difficult decisions with confidence. Instead of giving instant advice, it asks thoughtful questions, analyzes multiple options, identifies hidden biases, compares trade-offs using a decision matrix, and generates a personalized decision report with actionable recommendations.

## 🚀 Features

- AI-guided decision interview
- Multi-option comparison
- Decision matrix scoring
- Assumption and bias detection
- Premortem risk analysis
- 7-day decision validation plan
- Final AI verdict
- Shareable summary cards
- Responsive single-page HTML application


## 🎯 Key Learnings

- Breaking complex decisions into smaller questions leads to better clarity.
- Comparing options using objective criteria reduces emotional bias.
- Premortem analysis helps identify risks before committing.
- Testing assumptions is often more valuable than seeking certainty.
- A structured decision-making framework produces more confident and informed choices.
