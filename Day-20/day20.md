# 60 Days of Claude AI Challenge

# 🧩 Day 20 - Face Puzzle Game  
 

## 📌 Overview  
Today’s project was to build an interactive **Face Puzzle Game**. The idea started simple — capture a face using the webcam and convert it into a playable puzzle.  

As the project evolved, I focused on enhancing both functionality and user experience to make it feel more like a complete, polished application rather than just a basic implementation.


## 📂 Project File 
- 📄 [HTML File](./face-puzzle-game.html)  
- 🖼️ Screenshots provided below  

---

## ⚙️ Core Features Implemented  
- 📷 **Webcam Integration** with live preview and photo capture  
- 🧩 **Dynamic Puzzle Generation** with grid options (3×3, 4×4, 5×5)  
- 🖱️📱 **Drag & Touch Controls** for cross-device compatibility  
- ⏱️ **Timer & Move Counter** with real-time updates  
- ✅ **Win Detection System** with results screen  
- 🏆 **Leaderboard** stored using localStorage  

---

## 🚀 Enhancements & Additional Functionality  
- 🖼️ **Image Upload Option** (alternative to webcam capture)  
- 💡 **Hints System** (preview original image temporarily)  
- 👻 **Ghost Image Overlay** for guidance  
- 🔒 **Lock Correct Pieces** to prevent accidental movement  
- ↩️ **Undo Last Move** functionality  
- 🔀 **Smooth Shuffle Animation**  
- 📊 **Performance Rating System** (S, A, B, C)  
- 🔥 **Streak Tracking System**  
- 🎉 **Confetti Animation on Win**  
- 🌙☀️ **Dark/Light Mode Toggle**  
- ✨ **Glassmorphism UI Design** for a modern look

## 🎯 Key Learnings  
- Breaking down complex features into **manageable components**  
- Importance of **user experience (UX)** in interactive applications  
- Handling **real-time interactions** like drag, touch, and animations  
- Managing application state such as **moves, history, streaks, and leaderboard**  
- Enhancing projects with **visual polish and responsiveness**  


## 💭 Reflection  
This project showed how small, thoughtful enhancements can transform a simple idea into a much more engaging experience.  

It reinforced the importance of not just building features, but focusing on **how everything comes together** — from usability to design and performance.
