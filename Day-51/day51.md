# Interview & Approved Summary

## Project Overview

The selected capstone project is an **AI-Powered Code Review Platform** built using the MERN stack. The platform enables developers to authenticate with GitHub, browse their public repositories, select pull requests, and receive AI-generated code review feedback covering bugs, security vulnerabilities, performance improvements, and code quality recommendations.

To ensure the project remains achievable within a 10-day timeline, the MVP focuses on delivering a polished, production-ready experience rather than implementing every possible feature. AI-generated reviews will be displayed in a dedicated dashboard and stored for future reference. A lightweight standalone file review mode will also be included for users who want quick feedback without connecting a GitHub repository.

The stretch goal is to automatically publish AI review comments back onto GitHub pull requests after the core product is complete.

# Product Requirements Document (PRD)

## Problem Statement

Developers often spend significant time performing manual code reviews. Existing AI code review tools are frequently expensive, limited, or tightly integrated into enterprise ecosystems.

This project aims to provide an accessible AI-assisted code review platform that integrates directly with GitHub repositories while maintaining a clean and intuitive user experience.

## Target Users

- Software Engineers
- Students
- Open Source Contributors
- Freelance Developers

## Core Features

- GitHub OAuth Authentication
- Repository Browser
- Pull Request Selection
- AI-Powered Code Review
- Review Dashboard
- Review History
- Single File Review Mode

## Stretch Feature

- Automatically post AI-generated comments directly on GitHub Pull Requests.
