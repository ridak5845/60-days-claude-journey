# Day 33 – Media Integrity Analyzer

## Project Overview

For Day 33 of the **60 Days Claude AI Challenge**, I built a **Media Integrity Analyzer**—an interactive web application that teaches users how to critically evaluate online information before believing or sharing it.

The application guides users through two realistic scenarios that demonstrate how misleading headlines and emotionally manipulative content influence decision-making. After interacting with each scenario, users receive a detailed breakdown explaining the techniques used and practical strategies to identify similar patterns in real life.

# Media Integrity Dashboard

The final dashboard summarizes the user's performance across multiple categories:

- **Headline Accuracy**
- **Source Reliability**
- **Emotional Manipulation**
- **Audience Targeting**
- **Overall Media Integrity Score**
- **Biggest Red Flag Identified**
- **Personalized Learning Summary**
- **Three Practical Media Literacy Habits**

This dashboard provides users with actionable insights to improve their ability to recognize misleading or emotionally manipulative content online.


# Key Learnings

- Headlines don't have to be completely false to be misleading—they often exaggerate certainty to attract clicks.
- Words like **"proves," "instantly," "secret,"** and **"experts say"** can signal sensationalism rather than strong evidence.
- Emotional manipulation works by encouraging people to react before they think, often using fear, urgency, outrage, or curiosity.
- Credible information typically includes verifiable sources, context, and measured language instead of emotional pressure.
- Pausing to verify claims before sharing can significantly reduce the spread of misinformation.
- Interactive learning experiences are an effective way to improve media literacy because users experience manipulation before seeing the explanation.


# Conclusion

Building the **Media Integrity Analyzer** reinforced the importance of critical thinking in today's digital world. Rather than simply labeling content as true or false, the application helps users understand *why* certain headlines and posts are persuasive, encouraging thoughtful evaluation before engaging with or sharing online information.
