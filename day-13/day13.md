## **60 days Claude AI Challenge**

## **Day 13 – Job Search Analysis using Claude AI (Connector)**

As part of my 60 Days of Claude AI Challenge, today’s focus was on leveraging Claude with connectors to generate a data-driven job search analysis dashboard.

This project goes beyond simple job listings—it provides actionable insights, skill alignment, and market intelligence tailored for a fresher entering the data/AI domain.

#### **Discovered Opportunities**

-Identified 7 relevant job opportunities across India, all fresher-friendly

Top roles include:
-AI & Data Engineering Intern (92% match)
-AI/ML Developer (Junior) (88% match)
-Data Analyst Intern (Remote) (85% match)
-Mix of internships + full-time roles, enabling both learning and earning pathways
-Opportunities span across key hiring hubs like Pune, Bengaluru, Ahmedabad, and Remote roles
-Majority of roles require Python + SQL + basic ML understanding, aligning with current industry expectations

#### **Skill Gap Analysis**

The analysis highlighted a few critical gaps that directly impact job readiness:

**High Priority Gaps**

-Power BI / Data Visualization Tools
-Practical ML Portfolio (real-world projects on GitHub)

**Medium Priority Gaps**

-Cloud Fundamentals (Azure / AWS)
-Advanced SQL (CTEs, Window Functions)

#### **Insight:** 
While core technical skills exist, lack of proof-of-work (projects + tools) is the biggest gap—not theoretical knowledge.

**Market Insights**

- 35% YoY growth in Data Analyst roles in India
- Top hiring cities:
   Bengaluru, Hyderabad, Pune, Delhi NCR
- Remote roles are limited for freshers
- Salary benchmarks:
   Internships: ₹10k–25k/month
   Entry-level roles: ₹2.5L–8L/year
  MNC roles: Up to ₹12L/year
  -Candidates with certifications (IBM, Deloitte, etc.) receive 2× more shortlisting chances

**Insight:**
The market strongly favors skill + certification + portfolio combination

#### **Key Learnings**

-Having skills is not enough—visibility through projects (GitHub) is crucial
-Power BI is a must-have, appearing in ~80% of Data Analyst roles
-Early applications (within 7 days of posting) significantly increase response rates
-Location flexibility (targeting metro cities) can 5× opportunities
-Combining AI + Data + Development (MERN) creates a strong differentiator

#### **Conclusion**

This exercise showed how Claude AI can transform raw job data into strategic career insights.

-> Instead of blindly applying, I now have:

-A clear understanding of where I stand
-A focused roadmap on what to improve
-A smarter approach to target the right opportunities
