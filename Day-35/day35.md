# Day 35 – Prompt Puzzle 

## 60 Days of the Claude AI Challenge

## 📝 Overview

**Prompt Puzzle** is an interactive learning game designed to improve AI prompt engineering skills through hands-on challenges. Instead of simply writing prompts, players build, refine, and evaluate prompts across different scenarios, learning how clarity, specificity, structure, and constraints directly influence AI-generated outputs. The game provides instant feedback, optimized prompt examples, and a performance report to help identify areas for improvement.

## 💡 Key Learnings

- Effective prompts are **clear, specific, and structured**.
- Defining the **desired output format** reduces ambiguity.
- Avoid adding unnecessary instructions that distract from the main task.
- Small details like output column names, sorting, and constraints improve AI responses.
- Prompt engineering is about **precision, not prompt length**.
