# **60 Days of Claude AI Challenge**

# **Day 17 - AI Vehicle Cost & Fuel Analysis Dashboard**

An AI-powered interactive dashboard designed to analyze and compare different vehicle fuel types based on cost efficiency, emissions, maintenance, and real-world usability.

This project transforms raw data into actionable insights, helping users make smarter, data-driven decisions when choosing a fuel type.

## Project Overview

Choosing the right fuel type is no longer just about price. This dashboard provides a multi-dimensional comparison across:

-Cost per kilometer
-CO₂ emissions
-Maintenance cost
-Refueling/charging time
-Vehicle age impact on cost



## Key Features

- Cost per KM Comparison (Bar Chart)
- CO₂ Emissions Analysis (Donut Chart)
- Cost Trend vs Vehicle Age (Line Chart)
- E85 Suitability Score (Gauge Visualization)
- Fuel Type Comparison Cards
- Real-world dataset insights (52 vehicles, 5 fuel types)

## Key Insights from the Dashboard

**->E85 (Flex-Fuel)**

-Cost: ₹6.37/km (≈3.6% higher than petrol)
-Lowest CO₂ emissions (0.070 kg/km)
-Best suited for eco-conscious, low-mileage users

**->Electric Vehicles (EVs)**

-Lowest cost overall: ₹1.75/km
-Lowest maintenance cost
-Limited by charging infrastructure and time

**->CNG**

-Most economical combustion fuel: ₹3.32/km
-Ideal for budget-focused city driving

**->Petrol & Diesel**

-Strong in convenience and refueling speed
-Higher emissions and long-term cost impact

#### Core Insight:
-> There is no single “best” fuel — the right choice depends on trade-offs between cost, sustainability, and convenience.

**->Key Learnings**

-Learned how to translate raw datasets into meaningful insights using AI
-Improved skills in data storytelling through visualization
-Understood how to design multi-metric comparison systems
-Gained experience in building interactive dashboards using vanilla JavaScript
-Realized the importance of balancing performance, sustainability, and user context in decision-making tools
