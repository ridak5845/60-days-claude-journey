Not just built. Debugged, hardened, and shipped.

The parts of engineering that don't show up in a tutorial — surfaced and solved in the open, across ten real days.

01

Full-Stack Engineering

MERN stack, OAuth 2.0, a persisted data model that evolved deliberately as real requirements emerged.

02

AI Integration, Defensively

Schema validation and retry logic for a non-deterministic LLM API — surviving two live SDK/model deprecations mid-build.

03

Evidence-Based Debugging

A DNS quirk, a hidden placeholder bracket, a missing git push — each one solved with data, not guesses.

04

Production Deployment

Two separate free-tier platforms, real environment variables, real cold-start constraints, real fixes.

05

Security & Accessibility

Rate limiting, input validation, a caught-and-reverted CSRF regression, WCAG contrast fixes, keyboard navigation.

06

Judgment Under Ambiguity

Surfacing scope conflicts and trade-offs explicitly — JWT vs. sessions, QA vs. stretch goals — instead of guessing quietly.
