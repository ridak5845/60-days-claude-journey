# 🧠 Key Learnings

## Technical Learnings

* Implemented **JWT-based authentication** using secure HTTP-only cookies.
* Integrated **GitHub OAuth** for real-world user authentication.
* Built a **repository → pull request → file review workflow** using GitHub APIs.
* Designed reusable **Express route/service architecture** for scalability.
* Improved frontend state management with **React Hooks and React Router**.
* Learned deployment considerations for **Vercel + Render free-tier environments**.
* Added defensive error handling for external API failures and expired sessions.

## Product & Engineering Learnings

* Shipping a small **complete product** is more valuable than building many unfinished features.
* Writing **daily summaries and retrospectives** greatly improves decision-making.
* Clear **system design documentation** reduces debugging time later in the sprint.
* Separating **core v1 scope** from stretch goals prevented feature creep.
* Consistent incremental progress compounds dramatically over 10 focused days.
