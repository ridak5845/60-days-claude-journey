# Day 48 – The Verdict Engine ⚖️🤖

### 60 Days of Claude AI Challenge

## Overview

**The Verdict Engine** is an AI-powered decision support application that researches multiple options, scores them against customizable criteria, and produces a transparent, evidence-based recommendation.

For this project, I built a laptop comparison tool for developers and analysts that allows users to assign importance to different decision factors and instantly receive a weighted verdict.

---

# Project Features

- 🎯 Adjustable priority sliders for each decision criterion
- 📊 Live weighted scoring algorithm
- 🏆 Real-time ranking updates
- 📈 Transparent scoring table
- 📚 Research-backed source references
- 💻 Clean, responsive dark-themed interface
- ⚡ Instant verdict generation

---

# Technologies Used

- HTML5
- CSS3
- JavaScript
- Claude AI (Anthropic)
- Manual research from official manufacturer specifications and trusted review websites

# Key Learnings

### 1. Decision quality improves when priorities are explicit.

Different users value different factors, so allowing adjustable weights creates more personalized recommendations.

### 2. Transparency builds trust.

Showing the scoring methodology and source references makes AI-generated recommendations easier to understand and verify.

### 3. Small changes in priorities can significantly affect rankings.

Increasing the importance of battery life or price can completely change the final recommendation.

### 4. Research-backed data is more valuable than relying on specifications alone.

Combining official specifications with trusted third-party reviews provides a balanced evaluation.

### 5. Interactive visualizations make complex comparisons easier.

Real-time score updates help users quickly understand the impact of their preferences.

---

# Project Outcome

The Verdict Engine demonstrates how AI can assist in making informed, transparent, and personalized decisions by combining structured evaluation, weighted scoring, and credible research sources.
