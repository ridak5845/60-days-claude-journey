Loop Builder

Turn any one-shot prompt into a looping prompt — one where Claude checks its own work against your criteria and keeps improving it until your stop condition is met, instead of stopping after one draft. Fill in each step below; we keep it guided so you don't need to write the loop logic yourself.

1
Starting prompt
The normal, one-shot task you'd otherwise send once. This becomes the seed the loop repeats and improves on.
2
Goal
What "done" looks like in concrete terms — this is what every iteration is measured against.
3
Evaluation criteria
How Claude should judge each draft before deciding whether to loop again. Pick what matters most for this task.
4
Improvement strategy
How Claude should revise between iterations, so it changes the right things instead of guessing.
5
Stop conditions
When the loop should end — so it doesn't run forever or stop too early.
6
Safety rules
Guardrails so the loop stays predictable and never does anything you didn't ask for.
Show reasoning for each iteration, not just the final result
Never change the original goal or requirements mid-loop
Pause and ask before any destructive/irreversible action
Always report iteration count and final status
